# Plantilla: agente probador

Laboratorio 2 del webinar «Del prompt a la prueba» (UBE · Rama Estudiantil IEEE, 2-oct-2026).

**Uso rápido sin instalar nada:** abre cualquier chat de IA, pega el contenido de `AGENTS.md`, luego `Contexto/modulo.md` (completado) y una skill, y pide: «Aplica la skill a mi módulo y dame 5 casos».

**Laboratorio 3 (flujo probador → atacante → humano):** con la suite que obtengas, abre un chat con **otro** modelo y pregunta: «¿Cómo harías que esta suite pase sin que el sistema mejore? Da 3 formas». Luego revisa tú: ¿alguna prueba quedó más débil?, ¿algún umbral bajó?, ¿se ejecutó de verdad?
