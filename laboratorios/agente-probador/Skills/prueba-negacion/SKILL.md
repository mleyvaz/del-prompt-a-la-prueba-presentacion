# Skill: prueba de negación (P y «no P»)

**Objetivo:** comprobar que el modelo entiende la negación (prueba metamórfica).

1. Escribe 5 afirmaciones P de verdad conocida (sumas, fechas, comparaciones).
2. Escribe su negación «no P» para cada una.
3. Pregunta P y «no P» **en llamadas separadas** (chat nuevo cada vez), pidiendo una sola palabra: True / False / Cannot tell.
4. Cuenta:
   - **Hueco:** responde False a P y también a «no P».
   - **Contradicción:** responde True a ambas.
5. Un razonador coherente dice True a exactamente una de las dos. Reporta huecos y contradicciones.

Ejemplo: «The year 1818 came before the year 1718» / «The year 1818 did not come before the year 1718».
